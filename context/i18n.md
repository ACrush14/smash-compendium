# Sistema: Internacionalização (i18n)

**Arquivo de strings:** `lib/ui-i18n.ts`
**Arquivo de tradução:** `app/api/translate/route.ts`

---

## Idiomas Suportados

| Código | Nome | Fonte dos textos |
|---|---|---|
| `EN` | English | `contentEn`, `curatorOverviewEn` (banco) |
| `PT` | Português BR | `contentPt` (banco) ou tradução automática via Claude Haiku |
| `JP` | 日本語 | `contentJp` (banco) |
| `JP_EN` | 日本語 + EN | `contentJpEn` (banco) |

## Seleção de Idioma

O estado `lang: Lang` é gerenciado em `FighterRightPanel` (Client Component) e passado para `FighterDataZone` e `OriginGamesPanel`.

```typescript
type Lang = "EN" | "PT" | "JP" | "JP_EN";
```

## Exibição por Idioma — Origin Games

| Lang | Título do jogo | Data | Console | Capa |
|---|---|---|---|---|
| EN / PT | `name` | `yearNa.monthNa` (ou `year`) | `consoleFullEn` | `boxArtPath` |
| JP / JP+EN | `titleJp` (ou `name`) | `year.month` | `consoleFull` | `boxArtPathJp` (ou `boxArtPath`) |

## Tradução Automática PT-BR

**Endpoint:** `POST /api/translate`
```typescript
// Request
{ texts: { bio_SSB64: "...", bio_SSBM: "...", overview: "..." } }
// Response
{ translated: { bio_SSB64: "...", bio_SSBM: "...", overview: "..." } }
```

**Modelo:** Claude Haiku (`claude-haiku-4-5`)
**Quando é chamada:** nenhuma página do site chama mais essa rota; ela existe para o admin e para scripts. Bios sem `contentPt` usam o texto já traduzido no banco ou caem para EN.
**Acesso (V00.241):** exige o cookie de admin (`middleware.ts`), valida o corpo (`texts` só com strings, ≤ 50 itens e ≤ 20.000 caracteres) e limita 20 requisições/min por IP. Sem login responde 401.

**Chave:** `ANTHROPIC_API_KEY` fica no `.env.local` local. Na Vercel só é necessária se você for traduzir pelo site publicado, já logado como admin.

## Bio no Banco (FighterBio)

```typescript
// Para cada fighter × smashGameVersion:
{
  contentEn:    string   // obrigatório — texto EN da SSBWiki
  contentPt:    string?  // tradução PT (se disponível)
  contentJp:    string?  // texto JP original
  contentJpEn:  string?  // transliteração EN do JP
}
```

## Fallback de Idioma

| Lang | Fallback |
|---|---|
| PT | contentEn (se contentPt nulo e API falha) |
| JP | "— bio not available in JP —" |
| JP+EN | contentEn (se contentJpEn nulo) |
